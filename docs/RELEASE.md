MemeRoom 0.6.0, projet original de Rose Roubaud.

- Meilleur maintien de l’overlay au-dessus des fenêtres plein écran sans bordure, sans prise du focus ni des interactions.
- Code public, licence CC BY-NC-SA 4.0, guide de contribution et documentation technique.
- Exclusion des données et fichiers locaux sensibles via `.gitignore`.
- Installateurs Windows, Linux, Mac Apple Silicon et Intel, avec archive serveur complète.
- Liens vers le code et la licence sur la page de téléchargement.

Le plein écran exclusif de certains jeux nécessite de passer en sans bordure. Les builds Windows et Mac restent sans certificat éditeur officiel ; les limites d’installation et procédures sont dans DEPLOYER.md. Le serveur existant doit être mis à jour séparément ; les données des rooms et les préférences locales sont conservées.
